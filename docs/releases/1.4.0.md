# Phone Use 1.4.0

Agent 现在可以通过 App、ADB 或两者一起操作同一台手机。CLI 和 stdio MCP 使用同一套工具。桥接核验两条连接来自同一台设备后，保留首次登记的 `device_id`。

- **仅 ADB**：电脑安装 Android Platform Tools 并取得调试授权后，即可截图、按坐标点击和长按、两点滑动，以及返回主页或最近任务。手机无需安装 APK。
- **App 与 ADB 配合**：中文选区替换由 App 的无障碍服务执行。发送语音还需要 ADB helper、可用的音频路由和兼容的目标录音应用。用 `get_capabilities` 检查当前可用能力。
- **连接切换**：连接变化后重新观察，再使用新的快照操作。结果未知的动作不会转交另一端重复执行。

使用 App 模式时，下载适用于 Android 11 及以上版本的 `PhoneUse-1.4.0.apk`。从同签名的 1.3.0 覆盖升级可保留已有配对。电脑端请同步更新 CLI 或 stdio MCP；离线接入包为 `phone-use-1.4.0.zip` 和 `phoneuse-mcp-1.4.0.zip`，校验值见 `SHA256SUMS.txt`。[接入与验收步骤](https://github.com/nidhoggfgg/PhoneUse/blob/v1.4.0/docs/usage.zh-CN.md)

## English

The CLI and stdio MCP bridge can control a phone over the App, authorized ADB, or both. Once the bridge verifies that both connections reach the same device, the agent keeps the original `device_id`.

ADB alone supports screenshots, coordinate taps and long presses, two-point swipes, and system navigation. Connect the App for node-based actions and selection-aware text editing. Voice messages require both the App and an ADB helper, a working audio route, and a compatible recorder. Check `get_capabilities` after changing connections and obtain a fresh observation before acting.

For App mode, install `PhoneUse-1.4.0.apk` on Android 11 or later. Update the host bridge as well. The release includes offline Skill and MCP ZIPs and SHA-256 checksums. [Usage and verification guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.4.0/docs/usage.md)
