# Phone Use 1.2.0

本版在同一个 8443 端口兼容 HTTP 与 HTTPS，新增本机 HTTP 控制台和可选的远程 HTTP 连接。

## 下载与升级

- 下载 `PhoneUse-1.2.0.apk`，在 Android 11 或更新版本上安装。
- 从 1.1.0 升级保留 HTTPS 公钥绑定和已有配对；MCP／Python 客户端继续使用 HTTPS，不自动降级。
- “打开 Web 控制台”始终打开 `http://127.0.0.1:8443/`。HTTP 与 HTTPS 使用独立的浏览器 Cookie，切换协议可能需要重新配对。
- `phone-use-1.2.0.zip` 和 `phoneuse-mcp-1.2.0.zip` 分别提供离线 Skill 与 MCP 接入包；`SHA256SUMS.txt` 提供文件校验值。

## 主要变化

- 本机回环 HTTP 始终可用；非回环 HTTP 默认拒绝。
- 新增“允许不安全的 HTTP 连接”设置，默认关闭、持久化保存、切换立即生效。关闭时断开已有远程 HTTP 连接，并使其排队任务与等待中的观察失效。
- HTTP 仍需正常配对和鉴权，保留同源限制及 DNS 重绑定防护。HTTP 不加密屏幕内容、操作或凭据。
- App 展示非回环网络地址及显式配置的公网地址，默认展示 HTTPS，开启设置后额外展示 HTTP。公网可达性和端口映射仍由部署环境负责。
- 新增浅色、深色和跟随系统的主题设置，修复浏览器会话检查与配对批准之间的 Cookie 竞争。

详情见[使用说明](https://github.com/nidhoggfgg/PhoneUse/blob/v1.2.0/docs/usage.zh-CN.md)和[传输安全说明](https://github.com/nidhoggfgg/PhoneUse/blob/v1.2.0/docs/transport-security.zh-CN.md)。

## English

This release supports HTTP and HTTPS on the same port, 8443. Download `PhoneUse-1.2.0.apk` for Android 11+. Upgrades from 1.1.0 preserve HTTPS public-key bindings and existing pairings. MCP/Python clients continue to require HTTPS without automatic downgrade.

The app's web console button always opens `http://127.0.0.1:8443/`. Loopback HTTP is always available. Remote HTTP requires the new **Allow insecure HTTP connections** setting, which is off by default, persists across restarts, and takes effect immediately. Disabling it disconnects active remote HTTP requests and invalidates their queued work and ongoing observations.

Both transports require pairing and authorization, with same-origin restrictions and DNS rebinding protection. HTTP does not encrypt screen content, actions, or credentials. HTTP and HTTPS use separate browser cookies, so switching schemes may require pairing again.

The app displays non-loopback network addresses and an explicitly configured public address, adding HTTP URLs only when enabled. Routing and port forwarding remain the deployment's responsibility. This release also adds light, dark and system themes and fixes the browser session-check race with pairing approval.

Versioned Skill and MCP ZIPs are available for offline installation, with checksums in `SHA256SUMS.txt`. See the [usage guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.2.0/docs/usage.md) and [transport security guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.2.0/docs/transport-security.md).
