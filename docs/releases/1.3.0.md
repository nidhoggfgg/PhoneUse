# Phone Use 1.3.0

复制 App 中的提示词给 AI，即可安装 Skill 并开始配对。本版还改进了后台保活、权限引导和连接地址设置。

## 下载与升级

- 下载 `PhoneUse-1.3.0.apk`，安装到 Android 11 或更新版本的手机。
- 从 1.2.0 升级保留已有配对和 HTTPS 公钥绑定。旧的公网地址设置会迁移为访问地址白名单；需要继续使用的手机 IP 也应加入列表。
- `phone-use-1.3.0.zip` 和 `phoneuse-mcp-1.3.0.zip` 提供离线 Skill 与 MCP 接入包，`SHA256SUMS.txt` 提供校验值。

## 主要变化

- **从手机连接 AI**：在「连接 AI」卡片选择地址、复制完整提示词。AI 从手机下载并校验随 App 分发的 Skill，安装后发起配对；核对八位码、在手机授权并向 AI 确认后即可操作。
- **自动启动与后台保活**：打开 App 自动启动服务；新增后台保活开关，以及电池优化、自启动和通知设置引导，首页展示保活状态。
- **更清晰的权限提示**：突出无障碍权限状态和开启步骤；启动应用后检查目标是否进入前台，未确认时提供后台启动权限提示与通知。
- **连接地址管理**：新增地址选择器，优先展示 IPv4；访问地址白名单替代公网地址设置，同时明确本机 HTTP 与可选远程 HTTP 的范围。
- **文档与案例**：更新中英文 README，加入手机操作案例与简明上手流程。

后台保活仍受 Android 和厂商策略限制。强行停止后需重新打开 App；无障碍授权被关闭后需手动开启。操作期间保持手机亮屏、解锁。

详见[使用说明](https://github.com/nidhoggfgg/PhoneUse/blob/v1.3.0/docs/usage.zh-CN.md)和[AI 接入指南](https://github.com/nidhoggfgg/PhoneUse/blob/v1.3.0/docs/integrations.zh-CN.md)。

## English

Copy the setup prompt from the app to your AI to install the Skill and start pairing. This release also improves background operation, permission guidance, and connection settings.

Download `PhoneUse-1.3.0.apk` for Android 11+. Upgrading from 1.2.0 preserves saved pairings and HTTPS key bindings. An existing public-address setting migrates to the access address allowlist; add any phone IPs you still need to use.

- **Connect from the phone**: choose an address in **Connect your AI** and copy the complete prompt. The agent downloads and verifies the bundled Skill, installs it, and starts pairing. Compare the eight-digit code, approve on the phone, and confirm the match to the agent.
- **Automatic startup and background keep-alive**: opening the app starts its service. A keep-alive setting includes battery, autostart, and notification guidance, with status shown on the dashboard.
- **Permission and app-launch guidance**: the dashboard highlights Accessibility setup. App launches check for the target in the foreground; unconfirmed launches show permission guidance and a notification.
- **Connection settings**: an address selector prioritizes IPv4. An explicit access address allowlist replaces the public-address setting, with clearer rules for local and optional remote HTTP.
- **Documentation**: refreshed English and Chinese READMEs include phone-use examples and a shorter setup flow.

Android and vendor policies can still stop background operation. Reopen the app after a force-stop and manually re-enable Accessibility if it was revoked. Keep the phone awake and unlocked during use.

Offline Skill and MCP packages are available as `phone-use-1.3.0.zip` and `phoneuse-mcp-1.3.0.zip`, with checksums in `SHA256SUMS.txt`. See the [usage guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.3.0/docs/usage.md) and [AI integration guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.3.0/docs/integrations.md).
